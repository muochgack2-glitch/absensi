================================================================================
FIX N8N EXPRESSIONS - URL MUST START WITH "="
================================================================================

PROBLEM FOUND IN SCREENSHOT:
- URL field shows: https://absensi.smkpgriblora.sch.id/wa-reply?phone={{ $json.phone }}&message=...
- Expression NOT EVALUATED (still shows {{ }})
- Result: phone is null

ROOT CAUSE:
In n8n HTTP Request node, expressions in URL are ONLY evaluated if the URL field
starts with "=" character.

WITHOUT "=":
URL: https://absensi.smkpgriblora.sch.id/wa-reply?phone={{ $json.phone }}
Result: Literal string, NOT evaluated → phone=null

WITH "=":
URL: =https://absensi.smkpgriblora.sch.id/wa-reply?phone={{ $json.phone }}
Result: Expression evaluated → phone=6285216343400

================================================================================
HOW TO FIX IN N8N UI:
================================================================================

1. Open workflow in n8n editor
2. Click node "Send to WhatsApp"
3. In URL field, ADD "=" at the beginning:

BEFORE (WRONG):
https://absensi.smkpgriblora.sch.id/wa-reply?phone={{ $json.phone }}&message={{ encodeURIComponent($json.message) }}

AFTER (CORRECT):
=https://absensi.smkpgriblora.sch.id/wa-reply?phone={{ $json.phone }}&message={{ encodeURIComponent($json.message) }}

4. Save workflow
5. Test again

================================================================================
WHY THIS HAPPENS:
================================================================================

n8n has TWO modes for text fields:

1. STATIC MODE (default):
   - Text is used literally
   - {{ }} is treated as literal text
   - No expression evaluation

2. EXPRESSION MODE (enabled by "=" prefix):
   - Text is evaluated as expression
   - {{ }} expressions are resolved
   - Dynamic values work

The "=" at the start tells n8n: "This field contains expressions, evaluate them!"
