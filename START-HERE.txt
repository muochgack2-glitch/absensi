LANGKAH 1: Buat Database (via aaPanel)
═══════════════════════════════════════════════════════════════
1. Login ke aaPanel
2. Klik menu "Database"
3. Klik "Add Database"
4. Isi form:
   ┌─────────────────────────────────────────┐
   │ Database Name  : absensi_db             │
   │ Username       : absensi_db             │
   │ Password       : password               │
   │ Access Host    : localhost              │
   └─────────────────────────────────────────┘
5. Klik "Submit"

✓ Database siap!


LANGKAH 2: Deploy Aplikasi (ONE COMMAND)
═══════════════════════════════════════════════════════════════

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ Error: "Connection refused" atau "Database not found"
   → Pastikan database 'absensi_db' sudah dibuat di aaPanel
   → Test koneksi: 
     mysql -u absensi_db -p absensi_db
     (password: password)

❌ Error 500 / Blank page
   → Cek log error:
     tail -f /www/wwwroot/absensi/storage/logs/laravel.log
   
   → Fix permission:
     chmod -R 775 /www/wwwroot/absensi/storage
     chmod -R 775 /www/wwwroot/absensi/bootstrap/cache

❌ Assets tidak load (CSS/JS 404)
   → Rebuild assets:
     cd /www/wwwroot/absensi
     npm run build
     php artisan view:clear

❌ "Please configure database" atau migration error
   → Cek .env:
     nano /www/wwwroot/absensi/.env
     
   → Pastikan baris ini benar:
     DB_DATABASE=absensi_db
     DB_USERNAME=absensi_db
     DB_PASSWORD=password
   
   → Run migration lagi:
     php artisan migrate --force
