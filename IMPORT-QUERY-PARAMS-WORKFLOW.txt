================================================================================
TROUBLESHOOTING COMMON ISSUES:
================================================================================

ISSUE: Webhook 404 not found
SOLUTION: Workflow belum di mode Production atau belum Active

ISSUE: Error in workflow
SOLUTION: Cek execution logs untuk detail error

ISSUE: Phone or message null
SOLUTION: Cek data flow di execution logs - pastikan Parse Input output benar

ISSUE: WhatsApp tidak terkirim tapi n8n success
SOLUTION: 
- Cek WhatsApp Gateway status: curl http://localhost:3001/status
- Cek WhatsApp Gateway logs: pm2 logs whatsapp-absensi
- Pastikan WA Gateway connected
